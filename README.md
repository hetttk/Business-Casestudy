# Unlocking Revenue: Identifying Bottlenecks in Regional Sales Pipeline

## Project Overview

This project was developed as part of a Business Analyst practical examination. The objective of the project is to analyze regional sales data and identify business bottlenecks, underperforming regions, revenue losses, customer return patterns, and sales opportunities.

The analysis was performed using SQL for data extraction and Power BI for dashboard visualization.

---

## Tools Used

* MySQL Workbench
* Power BI Desktop
* Microsoft Excel / CSV Dataset

---

## Dataset Information

Dataset Name: RegionalSales2025.csv

Columns Used:

* OrderID
* Date
* CustomerID
* Region
* ProductName
* Category
* Quantity
* UnitPrice
* TotalAmount
* OrderStatus
* SalesAgent

Total Records: 5000

## SQL Analysis Performed

The following analyses were completed using SQL:

1. Monthly Sales Trend Analysis
2. Cancellation and Return Percentage by Region
3. Revenue Loss due to Cancelled and Returned Orders
4. Average Order Value by Product Category
5. Top 5 Performing Sales Agents
6. Category Contribution to Total Sales
7. Customers with High Return Frequency
8. Region Revenue Ranking
9. Most Returned Products
10. Sales Agent Cancellation Analysis

## Key Findings

* South region generated the highest revenue.
* West region showed the highest return rate.
* Home Appliances was the best-performing category.
* Rahul was the top-performing sales agent.
* Television was among the most returned products.

---

## Recommendations

1. Investigate the causes of high returns in the West region.
2. Improve inventory planning to reduce cancellations.
3. Monitor frequently returned products for quality issues.
4. Promote lower-performing categories to increase sales contribution.
5. Reward top-performing sales agents and share best practices.
